## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📦 Build & Deploy

```bash
npm run build
```

Deploy to **Vercel** (free):
1. Push this folder to GitHub
2. Go to [vercel.com](https://vercel.com) → New Project → Import your repo
3. Click Deploy — done! 🎉

## 💰 Monetization Setup

### 1. Google AdSense (Passive Income)
- Apply at [adsense.google.com](https://adsense.google.com)
- Once approved, uncomment the `<script>` tag in [`index.html`](./index.html) and replace `ca-pub-XXXXXXXXXXXXXXXX`

### 2. Contact Form via EmailJS (Free)
- Sign up at [emailjs.com](https://emailjs.com)
- Create a service + template
- Replace `YOUR_SERVICE_ID`, `YOUR_TEMPLATE_ID`, `YOUR_PUBLIC_KEY` in [`src/components/Contact.jsx`](./src/components/Contact.jsx)

### 3. Freelancing via Services Section
- Update your LinkedIn/GitHub URLs in `Hero.jsx` and `Footer.jsx`
- Share your portfolio URL on LinkedIn, Twitter, Upwork, Freelancer.com
